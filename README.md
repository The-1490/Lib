# Lib

Dự án dịch sách hướng dẫn sức khỏe (howtolivebetter) sang tiếng Việt.

## Trạng thái
- Kho lưu trữ vừa khởi tạo, đang chờ các chương đã dịch.
- Nguồn: `howtolivebetter-zh-e2605d3-full-v1.pdf` (Tiếng Trung, 884 trang, ~14 MB).
- Ngôn ngữ dịch mặc định: Tiếng Việt (số liệu gia đình: Anh - Tôi).

## Cấu trúc dự kiến
```
Lib/
├── README.md
├── Chương 01/
│   └── Chương_01.md
├── Chương 02/
│   └── Chương_02.md
└── ...
```

Mỗi chương được dịch riêng, xem lại thuật ngữ, rồi xuất ra PDF.
